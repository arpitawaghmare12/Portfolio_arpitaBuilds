ARPITA BUILDS — PERSONAL PORTFOLIO

A responsive portfolio website by Arpita Waghmare, highlighting selected work in AI/ML, data science, research, and backend development.

PROJECT STRUCTURE
- index.html: page structure, project cards, keyboard navigation, research, credentials, education, and contact sections
- style.css: responsive layouts, pastel/plum palette, visual effects, project-card polish, and reduced-motion styling
- script.js: interactive keyboard, typing effect, scroll progress, theme toggle, project filtering, certificate lightbox, and project detail dialogs
- assets/images/: portfolio portrait and Arpita_Anime.png
- assets/certificates/: certificate PDFs and preview images
- assets/documents/: résumé and published patent application document

FEATURED PROJECTS
1. DocuMind — PDF analysis and context-aware quiz generation using an LLM-powered workflow; Python, Gradio, Langflow/LangGraph, and Groq.
2. Parkinson's Disease Prediction Using Voice Data — experimental voice-feature modelling, feature selection/imbalance-handling exploration, and SHAP interpretability.
3. Hybrid ANN–Random Forest Climate Forecasting — time-aware environmental prediction experiment with regression evaluation and seasonal error analysis.
4. Todo List REST API — native Node.js HTTP server and task-oriented API logic without Express.
5. ForensicAI — research prototype exploring text-conditioned image generation and face-embedding similarity; experimental metrics are identified as project-reported and are not proof of identity.

RUN LOCALLY
Open index.html in a browser, or use a local development server such as VS Code Live Server. Keep the assets directory structure intact so image, PDF, and CSS/JS paths resolve.

DEPLOYMENT
The site is intended for static hosting such as GitHub Pages. Publish the folder containing index.html and its associated assets. Confirm the configured Pages source points to the correct folder.

NOTES
- Individual project links point to the author's GitHub profile until exact project repositories are published.
- The patent item is described as a published patent application, not as a granted patent.
- Parkinson's prediction and ForensicAI are experimental projects and should not be represented as clinically or forensically validated systems.
- Reported ForensicAI metrics require their experimental protocol and dataset context; they must not be interpreted as real-world identity verification.
